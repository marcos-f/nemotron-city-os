help & about

What this is

NemoCity is an agentic operations console: four real feeds (permits, microgrid telemetry, 911 incidents, warehouse video) flow into one substrate that judges, gates and ledgers every effect. An embedded copilot (NemoClerk) can drive almost everything in the product over the same API a human uses — except approving its own irreversible effect, which is refused by role, on the record.

What you can do without an account

  • Read the live ledger, the approval queue, feed and component status at the read-only guest console — the same data the public JSON API serves, rendered as a page instead of raw JSON.
  • Call the read-only JSON endpoints directly: /healthz, /overview, /feeds, /ledger, /approvals, /effects — all documented at /docs.
  • Ask NemoClerk questions from the guest console; it answers from the same grounded data and cannot act on your behalf.

What requires signing in

  • Approving, rejecting or releasing a held effect — always requires a verified human identity (OIDC or GitHub OAuth). There is no mock or one-click identity on this deployment.
  • Site configuration: roles, signal classes, gate policy, providers — admin role only.
