discovery

The same registry is readable three other ways, and they are held to agree with each other in CI: 

curl :8601/datasets                     # OpenAPI, per component
docket dataset show --id docket.seattle-permits    # CLI
mcp call list_datasets                  # MCP, read-only

Discovery is a read. There is no surface here — page, API, CLI or MCP — that changes a dataset's source or mode. That is a config edit in the owning component, accepted or refused by its loader, and every refusal is ledgered.
